# Mundos Minions

Dos juegos web en español: Mundo Creativo, de construcción voxel, y Minions Play Park, un parque de plataformas y bananas. Ambos incluyen diez personajes jugables, animación, controles de ratón/teclado y controles táctiles.

## Abrir

La portada permite elegir un juego. Pulsa Jugar, elige un personaje y entra al mundo.

- WASD: caminar; ratón: mirar; espacio: saltar.
- Doble espacio o F: volar; espacio/Shift: subir/bajar.
- E: inventario; 1–9 y 0: materiales; clic izquierdo/derecho: retirar/colocar.
- F5 o Vista: cambiar cámara. Esc: menú.
- En tablet: joystick, arrastre para mirar y botones táctiles.

## Guardado

Las construcciones se guardan en el navegador de cada dispositivo, por separado para cada juego. No hay sincronización entre dispositivos. Borrar los datos del navegador borra sus mundos: usa Menú → Guardar copia del mundo para descargar un respaldo JSON. Menú → Cargar copia del mundo permite restaurarlo o llevarlo a otro dispositivo; pide confirmación antes de reemplazar el mundo.

No se incluyen mundos personales, direcciones de red local, credenciales ni archivos del PC. El servidor local y los mundos del PC siguen siendo independientes de esta versión web.

## GitHub Pages

Sitio estático sin instalación de paquetes, servidor ni servicios de terceros. En Settings → Pages, selecciona Deploy from a branch, `main` y `/ (root)`. El archivo `.nojekyll` permite servir los archivos directamente.

## Créditos

Proyecto aficionado. Minions y sus personajes pertenecen a sus respectivos titulares. No es un producto oficial de Illumination, Universal, Minecraft ni Roblox, ni está afiliado a ellos. Los personajes son adaptaciones simplificadas para el juego.
